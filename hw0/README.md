# HW0: Setup and Day 1 snapshot

The full instructions are on Canvas (HW0 and the HW0 Setup Guide).

## What goes here

- `hello.py`: already here. Run it to check your setup.
- `day1.md`: **you add this.** Your Day 1 "before" snapshot (HW0 Part 2). Put your screenshot(s) in this folder too.

## Steps

1. Run the setup check from VS Code's terminal (it opens at the top of your repo):
   ```
   python3 hw0/hello.py
   ```
   (🪟 Windows: `python hw0/hello.py`)
2. Add `day1.md` and your screenshot(s) to this `hw0` folder, then:
   ```
   git add .
   git commit -m "Add Day 1 snapshot"
   git push
   ```
3. Refresh your repo on GitHub and check that `hw0/day1.md` is there.
4. Submit your **commit link** on Canvas (see the README at the top of this repo).

Stuck? Post in `#help` on Slack with a screenshot of the error.
